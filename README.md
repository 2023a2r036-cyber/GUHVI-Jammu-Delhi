# Global Urban Heat Vulnerability Index (GUHVI) Analysis
**Study Areas:** Jammu & Delhi, India

## About the Project
This repository contains the datasets and maps for my 7th-semester minor project on assessing urban heat vulnerability. The project calculates the **Global Urban Heat Vulnerability Index (GUHVI)** for two major cities: Jammu and Delhi, using satellite imagery.

## Methodology & Parameters
The vulnerability index is calculated by normalizing and combining three key parameters on a scale of 0 to 1:
1. **Exposure:** Land Surface Temperature (LST)
2. **Sensitivity:** Normalized Difference Built-up Index (NDBI)
3. **Adaptive Capacity:** Normalized Difference Vegetation Index (NDVI)
*Final Formula: GUHVI = (LST_Norm + NDBI_Norm) - NDVI_Norm*

## Files Included in this Repository
* `Delhi_GUHVI_Final_Data.csv`: Processed final dataset for Delhi with coordinates.
* `Jammu_GUHVI_Final_Data.csv`: Processed final dataset for Jammu with coordinates.
* `Delhi Heat Exposure (LST) map.pdf`: Map showing the temperature distribution in Delhi.
* `Jammu Vulnerability Index map.pdf`: Final normalized vulnerability map for Jammu.
